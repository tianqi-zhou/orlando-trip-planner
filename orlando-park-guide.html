你的三日落地版安排

顺序考虑了周末客流、Epic 暴晒/雷雨、9 月 11 日 USF 的 Halloween Horror Nights 提前清场，以及 Disney 周六较长营业时间。

9/9 周三
07:45 落地｜天气保险与拍照窗口不把它算作必须完成的付费乐园日，避免航班、取行李和入住延误造成损失；如果 10:30 前已经安顿好，可去 CityWalk / Disney Springs 拍照，或把你已有的可改期门票提前使用。
目前较一致的趋势是上午到午后前半段较适合拍照，午后雷阵雨风险上升。不要为了“多玩一天”临时买一张高价单日票。
9/10 周四
Epic Universe｜一整天建议 8:00 前到安检；若有 Early Park Admission 再提前。上午先清室外项目，下午雷雨时做室内。
推荐顺序：Battle at the Ministry（走完整普通队列）→ Mine-Cart Madness → Mario Kart → Hiccup’s Wing Gliders → Stardust Racers → Monsters Unchained → Curse of the Werewolf → Untrainable Dragon → 夜间补漏。
9/11 周五
Universal Studios Florida + Islands of Adventure9/10–9/13 每晚都有 HHN，换到周六也避不开 USF 17:00 清场；周五预测客流低于周六，所以仍选周五。必须买 Park-to-Park 才能坐 Hogwarts Express。上午先 USF，再乘火车去 IOA，晚上留给 Hagrid / VelociCoaster。
推荐顺序：Gringotts 普通队列 → Mummy → Transformers/MIB → Diagon Alley → Hogwarts Express → Forbidden Journey 普通队列 → Hagrid → VelociCoaster；闭园前二刷 Hagrid。
9/12 周六
Disney 一日精选｜默认 3 园，体力好再加 MKAK 8:00、EPCOT 9:00、HS 9:00、MK 8:00；当天 MK 预计开至 23:00。园区间尽量叫车，别用巴士硬耗时间。
稳妥版：AK FOP / Everest / Zootopia → EPCOT Guardians / Test Track / Remy → HS Rise / Muppets / Tower。挑战版再在 20:45 前离开 HS，去 MK 看 21:30 烟花及夜间低排队项目。
9/13 周日
不买全天乐园票18:40 从 MCO 起飞，建议 15:30 左右离开酒店/景点。安排 Disney Springs、CityWalk、酒店泳池或补购物；除非你已有低边际成本的多日票，否则半天票的性价比很差。

天气与拍照策略

奥兰多雷阵雨的具体小时会快速变化。以下把你看到的逐小时预报作为“保守情景”，再结合 NWS、AccuWeather、Weather Underground 的共同趋势安排；入园前一晚和当天早上必须重看雷达。

9/9 周三｜最佳备用拍照窗

07:45 落地后，如果行李与入住顺利，上午至 15:00 左右通常是最可利用的窗口。适合化完整妆、拍 CityWalk / Disney Springs，或仅在你已有灵活门票时提前入园。

9/10 周四｜Epic 主力日

目前趋势为炎热、上午较稳，午后到傍晚阵雨风险增加。开园先拍 Portal、魔法部与任天堂区，再刷所有室外过山车；Stardust 不再押到晚上才第一次坐。

9/11 周五｜预报分歧最大

你的 App 显示 08:30–12:00 和 18:00 后下雨；其他当前模型更偏向 15:00–19:00 雷阵雨。雨天鲁棒方案：上午 USF 室内 ride，雨停立即拍 Diagon Alley，并在 13:00–17:30 抢 Hagrid / VelociCoaster。

9/12 周六｜按高雨险处理

当前各源都认为有阵雨/雷暴风险，只是是否“从中午连续下到晚上”尚不一致。上午先做 AK 室外与照片；中午后转 EPCOT / HS 室内项目。MK 烟花作为 bonus，别把整天成功与否押在夜间表演。

化妆与拍照：底妆用轻薄防水型，睫毛膏/眼线选 waterproof；带吸油纸、粉饼、防水眉笔和密封袋。园内不建议一直穿闷热雨衣拍照——用折叠伞等雨停，拍摄前再脱雨衣、擦镜头。上午光线与妆面都更稳，重要人物照不要拖到午后。

小红书高频提醒，翻译成可执行动作

为什么环球仍放周五

9 月 10、11、12、13 日都有 HHN，USF 这几天都预计 17:00 对普通日票游客清场；换周六并不会多出 USF 夜间时间。公开客流预测中 9/11 明显低于 9/12，因此周五仍是老两园的更优解。若你本身想玩鬼屋，可另买 HHN 票把 USF 延长到深夜；否则 17:00 后专心刷 IOA。

Epic 晒 + 下午雷雨

园区开阔、遮阴不足，Yoshi、Fyre Drill 等慢速室外项目尤其晒。带帽、防晒、补盐、轻便雨衣；上午先清 Mine-Cart、Hiccup、Stardust。下午雷雨会让室外过山车长时间暂停，近期实测甚至 16:15–18:30 连续下雨。

Single Rider 不是永远更快

入口会随机开放/关闭，下午更容易关闭；Universal App 会显示。Mario Kart、Mine-Cart、Monsters、Hagrid、Gringotts、Forbidden Journey 常有机会显著省时，但座位/同伴分开且速度波动。现场先问 Team Member。

哈迷不要第一次就走单人

Battle at the Ministry、Gringotts、Forbidden Journey 的普通队列是世界观的一部分；Smugglers Run 的单人线也会错过 Hondo pre-show。第一次走 standby/Express 看完整故事，二刷才 Single Rider。你上次错过古灵阁内部，这次把“走完整队列”设为必做。

“速通”要买在瓶颈上

Epic 的热门并非全部必须 Express；早到的价值最大。Disney 一日跨园则相反：预约制 LL 能把跨园时间固定下来，购买价值更高。Premier Pass 只能在单一园区使用一次每项，不适合你的四园挑战。

9/10 Das Stakehaus：Epic 室内主题与效率兼顾；9/11 Leaky Cauldron：补上古灵阁完整动线后的哈迷正餐；9/12 Satu'li Canteen：Disney 跨园日最省时、质量也稳定。

下雨与排队策略

Quick Service 尽量在 10:45–11:15 或 14:00 后错峰，并提前在 App 下单。雷雨前不要把室内餐厅当作临时备选——所有人都会同时涌入；一看到雷达逼近，就先点餐再去室内项目。

效率原则：Epic 与 Disney 使用各自官方 App 的 Mobile Order；能选取餐时间就先锁时段。Mythos、Atlantic、Blue Dragon、Space 220 这类桌边服务通常会吃掉 60–120 分钟，本行程默认不安排。CityWalk 晚餐不占入园黄金时间，想吃 Toothsome / Cowfish 请订在 20:30 以后。
